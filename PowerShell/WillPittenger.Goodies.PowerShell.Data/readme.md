Consists of a series of PowerShell CmdLets with various data tasks in mind.  Currently, the only CmdLet provided is `Get-FileMetaData`.  That retrieves the metadata for a file.

# Dependencies

1. [WillPittenger.Goodies.JSON](https://www.nuget.org/packages/WillPittenger.Goodies.JSON/)

	1. [WillPittenger.Goodies.Tools](https://www.nuget.org/packages/WillPittenger.Goodies.Tools/)
